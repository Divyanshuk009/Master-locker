VaultLock — Windows File, Folder, Image & Video LockerVaultLock is a fast, lightweight Windows locker with both a modern GUI and CLI. Instead of slowly copying or re-archiving gigabytes of data, VaultLock locks any file, folder, image, or video in-place in under 0.1 seconds while keeping all internal contents completely untouched.On first lock, VaultLock generates a standalone <ItemName> Lock.exe right next to your protected item:Click once when unlocked -> Locks immediately in one click (no password prompt needed to re-lock).Click again when locked -> Prompts for your password and unlocks/opens your item.Master VaultLock.exe (masterLock.py) -> Centrally set passwords, unlock items, change passwords, or permanently remove locks and toggle executables.Key FeaturesInstant In-Place Locking (< 0.1s): Locks folders and files of any size (including large multi-GB video folders) using Windows NTFS Access Control Lists (icacls) without moving, renaming, or deleting any files inside.One-Click Companion Toggle (<Name> Lock.exe): Automatically compiles a tiny (~16 KB) native Windows executable beside each protected item for effortless one-click locking and password-protected unlocking.Master Control Panel: Manage all locked items from a single dark-mode interface—set up new locks, unlock items, change passwords, or remove locks cleanly.One-Click Standalone .exe Builder: Includes a built-in Build Master .exe button that packages masterLock.py into a standalone VaultLock.exe (no terminal required).Windows Explorer Integration: Add Manage Lock with VaultLock directly to your Windows right-click context menu in one click.Full GUI & CLI Support: Use the visual interface or automate lock/unlock/password workflows from Command Prompt or PowerShell.Salted PBKDF2-HMAC-SHA256 Password Verification: Passwords are never stored in plain text; every .vlock key file uses a unique 16-byte cryptographic salt and 200,000 PBKDF2-HMAC-SHA256 iterations.Quick StartPrerequisitesOS: Windows 10 or Windows 11Python: Python 3.8+ (with standard tkinter included)(Optional) PyInstaller: Only needed if you want to compile masterLock.py into a standalone VaultLock.exe (pip install pyinstaller).1. It will also automatically register the Windows Explorer right-click menu.Usage GuideGraphical User Interface (GUI)First-Time Lock Setup (Lock Setup tab):Select any file, image, video, or folder.Enter and confirm a password (minimum 4 characters).Click LOCK & CREATE ONE-CLICK .EXE.Your item is locked immediately, and <ItemName> Lock.exe + <ItemName>.vlock are created beside it.Daily One-Click Toggle (<ItemName> Lock.exe):To Unlock: Double-click <ItemName> Lock.exe, enter your password, and press Enter (automatically opens the folder/file if "Open after unlock" is checked).To Re-Lock: Double-click <ItemName> Lock.exe again—it locks immediately with a brief confirmation toast.Change Password (Change Password tab):Select the item (or its .vlock / Lock.exe file), enter your current password and new password, and click UPDATE PASSWORD. Both the Master app and <ItemName> Lock.exe immediately enforce the new password.Remove Lock (Remove Lock tab):Select the item, enter your password, and click REMOVE PASSWORD & DELETE TOGGLE .EXE to permanently restore permissions and delete the .vlock and <ItemName> Lock.exe files.Command-Line Interface (CLI)You can run all operations directly from Command Prompt or PowerShell using either python masterLock.py or VaultLock.exe:ActionCommandLock & create toggle .exepython masterLock.py lock "D:\Media\PrivateFolder" -p yourpasswordUnlock itempython masterLock.py unlock "D:\Media\PrivateFolder" -p yourpasswordChange passwordpython masterLock.py change-password "D:\Media\PrivateFolder" -p oldpass -n newpassRemove lock & toggle .exepython masterLock.py remove-lock "D:\Media\PrivateFolder" -p newpassOpen specific item in GUIpython masterLock.py "D:\Media\PrivateFolder"Tip: Omit -p / -n flags in CLI mode to be prompted securely without echoing passwords in terminal history.How It WorksAccess Control: VaultLock applies explicit NTFS Deny permissions (icacls /deny *S-1-1-0:(OI)(CI)(F)) on the target path, blocking unauthorized browsing, copying, or deletion in Windows Explorer and Command Prompt while leaving internal files untouched.Metadata & Verification: A companion <ItemName>.vlock JSON file stores the lock state (locked: true/false), random 16-byte salt, and PBKDF2-HMAC-SHA256 hash.Native Toggle Compilation: When locking an item for the first time, VaultLock invokes Windows' built-in .NET C# compiler (csc.exe) to compile a self-contained WinForms toggle executable (<ItemName> Lock.exe) tailored to that item—requiring zero Python runtime dependencies on the machine to lock or unlock.Important NotesKeep <ItemName>.vlock Beside the Item: <ItemName> Lock.exe relies on the companion <ItemName>.vlock file in the same directory to verify your password and track lock state. Do not delete the .vlock file manually while an item is locked.Remember Your Password: Because passwords are hashed with PBKDF2-HMAC-SHA256, there is no plain-text password recovery.NTFS Drives: Instant ACL locking requires an NTFS-formatted Windows drive (standard for internal Windows drives like C: and D:).LicenseThis project is open-source and available under the MIT License.
